# 📱 Финансовый питомец (Команда "Вектор кода")

Мобильное приложение для формирования базовых финансовых навыков у детей 7-11 лет.

## 🛠 Стек технологий
**Текущая версия (Прототип):**
- React 18 + TypeScript
- Vite (сборщик)
- Figma Make (генерация UI)

**Планируемый стек для финальной APK-сборки:**
- Kotlin
- Jetpack Compose
- Room (локальная БД)
- Офлайн-работа, без сервера и лишних разрешений

## 🚀 Запуск текущей версии (Прототип)
Поскольку текущая версия представляет собой веб-приложение, сгенерированное из Figma:
1. Установите зависимости: `npm install`
2. Запустите сервер разработки: `npm run dev`
3. Откройте ссылку в браузере (в т.ч. в мобильном браузере для проверки адаптивности).

*(Инструкция по сборке Android APK будет добавлена при переходе на стек Kotlin)*

## 🎮 Демонстрационный режим
Приложение работает полностью офлайн. Все данные в текущем прототипе хранятся в состоянии приложения, в финальной версии будет реализовано локальное хранение через Room.

## 📂 Структура проекта
- `src/` — исходный код компонентов приложения (React)
- `index.html` — точка входа
- `vite.config.ts` — конфигурация сборщика
- *(В финальной версии структура будет адаптирована под `data/`, `ui/`, `ui/navigation/` для Android)*

## ⚠️ Известные ограничения
- Пока нет финальной нативной APK-сборки (работа ведётся онлайн, код загружается поэтапно).
- Раздел взрослого и тексты заданий находятся в активной разработке.
- **Графика:** Авторские иллюстрации персонажей (Тоби и Ананас Татьяна) являются оригинальными работами художницы Маринетт Мортем. Письменное согласие автора на использование и распространение данных иллюстраций в составе прототипа получено. Они интегрированы в Figma-прототип и будут перенесены в финальную версию.

## 🔗 Интерактивный прототип
👉 **Ссылка на прототип в Figma:**  
https://www.figma.com/make/exk9vtddxKblwDvgoguyQW/Financial-Literacy-App-Prototype

Прототип демонстрирует 5 ключевых экранов:
1. **Приветствие** (знакомство с концепцией)
2. **Создание питомца** (ввод имени, выбор типа и цвета)
3. **Главный экран** (баланс, накопления, навигация)
4. **Планирование бюджета** (3 категории расходов)
5. **Накопления** (цель, прогресс, пополнение копилки)

*Все экраны связаны кнопками — можно пройти полный сценарий использования без регистрации.*
