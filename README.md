# ФинПитомец

Мобильное приложение для формирования базовых финансовых навыков у детей 7-11 лет.

## Стек технологий
- Kotlin
- Jetpack Compose
- Room (локальная БД)
- Без сервера, без ИИ, без лишних разрешений

## Сборка
1. Открой проект в Android Studio
2. Sync Gradle
3. Build → Build Bundle(s) / APK(s) → Build APK(s)
4. APK будет в `app/build/outputs/apk/debug/`

## Демонстрационный режим
Приложение работает полностью офлайн. Все данные хранятся локально.

## Структура
- `data/` — слой данных (Room entities, DAO, database)
- `ui/` — интерфейс (Compose screens, ViewModels)
- `ui/navigation/` — навигация между экранами

## Реализованные функции
- ✅ Создание питомца (имя, вид, цвет)
- ✅ Главный экран с балансом и статусом
- ✅ Планирование бюджета (3 направления)
- ✅ Локальное хранение данных
