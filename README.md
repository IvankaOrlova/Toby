## 📖 Описание проекта

Мобильное приложение для формирования базовых финансовых навыков у детей 7-11 лет через игровую механику с виртуальным питомцем.

Ребёнок создаёт собственного питомца (по умолчанию «Тоби», но имя можно изменить на любое), зарабатывает игровые монеты, выполняя задания, учится распределять бюджет по трём направлениям (обязательные расходы, желания, накопления) и копит на мечту вместе с персонажем-помощником копилкой «Ананас Татьяна».

Методическая основа приложения — авторская книга по финансовой грамотности для детей, на базе которой подготовлены тексты всех заданий.

## 🛠 Стек технологий

**Текущий этап (промежуточная сдача):**
- Интерактивный кликабельный прототип (Figma Make)
- Авторские иллюстрации персонажей (интегрированы в прототип)

**Планируемый стек для финальной APK-сборки:**
- Kotlin + Jetpack Compose
- Room (локальная база данных)
- Офлайн-работа, без сервера и без ИИ

## ⚠️ Известные ограничения текущего этапа

- Прототип требует подключения к интернету для открытия по ссылке Figma.
- В прототипе не реализовано реальное сохранение данных (перезагрузка страницы сбрасывает состояние). Это будет исправлено в финальной APK-сборке через локальную БД Room.
- В активной разработке: визуальная интеграция заданий в интерфейс, раздел взрослого, каталог покупок.
- **Графика:** Авторские иллюстрации персонажей (Тоби и Ананас Татьяна) являются оригинальными работами художницы Маринетт Мортем. Письменное согласие автора на использование и распространение данных иллюстраций в составе прототипа получено.
