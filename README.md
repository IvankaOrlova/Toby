## 📖 Описание проекта
Мобильное приложение для формирования базовых финансовых навыков у детей 7–11 лет через игровую механику с виртуальным питомцем.

Ребёнок создаёт собственного питомца (по умолчанию «Тоби», но имя можно изменить на любое), зарабатывает игровые монеты, выполняя задания, учится распределять бюджет по трём направлениям (обязательные расходы, желания, накопления) и копит на мечту вместе с персонажем-помощником - копилкой «Ананасом Татьяной».

## 🛠 Стек технологий

**Текущий этап (Промежуточная сдача):**
- Интерактивный кликабельный прототип (Figma Make), полностью реализующий пользовательские сценарии (User Flow).
- Готовые авторские иллюстрации, интегрированные в прототип.

**Планируемый стек для финальной версии:**
- Kotlin + Jetpack Compose (нативная Android-разработка)
- Room (локальная база данных для полностью офлайн-работы)
- Архитектура без серверной части и без использования ИИ (в соответствии с ТЗ)

## ⚠️ Технические ограничения текущего этапа (Прототипа)

- Прототип требует подключения к интернету для открытия по ссылке Figma.
- В прототипе не реализовано реальное сохранение данных (перезагрузка страницы сбрасывает состояние). Это будет исправлено в финальной APK-сборке через локальную БД Room.
- В активной стадии разработки: визуальная интеграция заданий из книги в интерфейс, расширение каталога покупок и реализация раздела взрослого.

## 🚀 Дорожная карта развития проекта (Roadmap)

Текущий интерактивный прототип полностью закрывает требования промежуточной сдачи и служит надёжным фундаментом для создания полноценной мобильной игры. Следующие этапы направлены на углубление геймификации и техническую реализацию:

- **Техническая реализация (Tech Lead):** Перенос логики прототипа в нативную среду Android (Kotlin + Jetpack Compose) с обеспечением полностью офлайн-работы (Room DB) и сборкой финального APK.
- **Контент и нарративный дизайн:** Интеграция адаптированных текстов заданий из авторской книги «Жанна экономит» непосредственно в игровой интерфейс. Проектирование ветвящихся нарративных сценариев и нелинейных пользовательских траекторий.
- **Геймификация и экономика:** Реализация полного игрового цикла: начисление монет за выполненные задания, масштабирование каталога покупок (≥8 позиций) и внедрение механики влияния прогресса ребенка на визуальное состояние и рост питомца.
- **Расширение функционала:** Разработка и внедрение «Раздела взрослого» для контроля прогресса и мягкой мотивации ребёнка.
