# 📱 Финансовый питомец (Команда "Вектор кода")

Мобильное приложение для формирования базовых финансовых навыков у детей 7-11 лет.

## 🛠 Стек технологий
**Текущий этап (Промежуточная сдача):**
- Интерактивный кликабельный прототип (Figma)
- Авторские иллюстрации персонажей (интегрированы в прототип)

**Планируемый стек для финальной версии (APK):**
- Kotlin
- Jetpack Compose
- Room (локальная база данных для офлайн-работы)

## 🚀 Как посмотреть проект (Демонстрация)
На текущем этапе основным результатом является **интерактивный прототип**, который полностью закрывает требование ТЗ п. 7.1.

1. Откройте ссылку на прототип в любом браузере (рекомендуется включить режим мобильного устройства или открыть с телефона):
   🔗 **https://www.figma.com/make/exk9vtddxKblwDvgoguyQW/Financial-Literacy-App-Prototype**
2. Нажмите кнопку "Начать" и пройдите полный сценарий: создание питомца → главный экран → планирование бюджета → копилка.
3. Исходный код приложения находится в стадии активной разработки и будет добавлен в этот репозиторий перед финальной сдачей.

## ✅ Соответствие требованиям ТЗ (Кейс 06)

| Требование | Статус в прототипе | Комментарий |
|---|---|---|
| 2.5.1 Первый запуск, гостевой режим | ✅ Реализовано | Экран приветствия с объяснением 3 типов решений |
| 2.5.2 Создание питомца (9 комбинаций) | ✅ Реализовано | 3 вида × 3 цвета, ввод имени ребёнком |
| 2.5.3 Главный экран | ✅ Реализовано | Питомец, баланс, накопления, цель, статус |
| 2.5.4 Игровая валюта и доход | 🔄 В работе | Будет реализовано в коде (начисление за задания) |
| 2.5.5 Планирование бюджета | ✅ Реализовано | 3 направления: обязательные/необязательные/накопления |
| 2.5.6 Покупки (≥8 позиций) | 🔄 В работе | Каталог в разработке |
| 2.5.7 Накопления и цель | ✅ Реализовано | Механика пополнения копилки "Ананас Татьяна" |
| 2.5.8 Задания (≥6 по 3 темам) | 🔄 В работе | Контент адаптируется |
| 2.5.10 Рост питомца (≥3 стадии) | ✅ Реализовано | 3 стадии заложены в модели и UI |
| 2.5.13 Сохранение состояния | ❌ Не в прототипе | Будет реализовано через Room в финальной APK-версии |

## ⚠️ Известные ограничения текущего этапа
- Прототип требует подключения к интернету для открытия по ссылке.
- В прототипе не реализовано реальное сохранение данных (перезагрузка страницы сбрасывает состояние). Это будет исправлено в финальной APK-сборке.
- Раздел взрослого и тексты заданий находятся в активной разработке.
- **Графика:** Авторские иллюстрации персонажей (Тоби и Ананас Татьяна) являются оригинальными работами художницы Маринетт Мортем. Письменное согласие автора на использование и распространение данных иллюстраций в составе прототипа получено.
